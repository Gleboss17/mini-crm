# Mini-CRM для учета клиентов и сделок

## Описание
Веб-приложение (Full-stack) для управления клиентами и сделками. Включает в себя авторизацию (JWT), базу данных (SQLite), роли (Админ/Менеджер) и интерфейс для работы.

## Стек технологий
* **Backend:** Node.js, Express, SQLite3, JWT, Bcrypt.
* **Frontend:** HTML5, CSS3, Vanilla JavaScript.
* **Тестирование:** Jest, Supertest.
